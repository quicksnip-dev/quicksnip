title: Third-party apps
description: Build extensions and integrations on top of QuickSnip's public data.
---

All QuickSnip data is static JSON. You can use it from anything: an editor plugin, a CLI, a chatbot, an MCP server.

## Endpoints

| URL | Contents |
| --- | --- |
| `https://www.quicksnip.app/data/snippets/index.json` | Every snippet's metadata: `id`, `category`, `slug`, `name`, `title`, `description`, `tags`, `contributors`, `languages`, `verified`, `installable` |
| `https://www.quicksnip.app/data/snippets/<category>/<slug>.json` | One snippet with `code` (per language), `usage`, `tests` and `installUrl` |
| `https://www.quicksnip.app/r/registry.json` | shadcn registry index |
| `https://www.quicksnip.app/r/<name>.json` | shadcn registry item |
| `https://www.quicksnip.app/llms.txt` | Plain-text index for language models |

Fetch `index.json` once and cache it. It changes only when snippets change.

## Rules

- **Attribute QuickSnip.** Link to [quicksnip.app](https://www.quicksnip.app) or the [GitHub repository](https://github.com/quicksnip-dev/quicksnip), and keep each snippet's contributors visible where reasonable.
- **Respect the MIT license.**
- **Tell us!** Open a discussion and we'll feature your project on the [Extensions](/extensions) page.
