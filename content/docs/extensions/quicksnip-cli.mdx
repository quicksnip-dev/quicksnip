> **Status: planned.** For JavaScript and TypeScript, use the [shadcn CLI](/guide/installation) today.

The QuickSnip CLI will bring one-command installs to every language in the collection:

```bash
npx quicksnip add slugify            # picks the language from your project
npx quicksnip add slugify --lang py  # or choose one
npx quicksnip search "relative time"
```
