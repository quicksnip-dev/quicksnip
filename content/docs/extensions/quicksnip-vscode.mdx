> **Status: planned.**

The VS Code extension will let you search QuickSnip from the command palette and insert or install a snippet into the current project.

Until then, you can:

- Use the [shadcn CLI](/guide/installation) from VS Code's terminal.
- Give your AI assistant (Copilot, Claude Code, Cursor, …) the [QuickSnip agent instructions](/guide/for-ai-agents).

Want to build it? Open a discussion on [GitHub](https://github.com/quicksnip-dev/quicksnip/discussions).
